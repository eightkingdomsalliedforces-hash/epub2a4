# 參考封底版型與 ISBN 顯示清理設計

## 背景

目前「出版社式封底」只依安全區百分比粗略分配 ISBN、條碼、出版資訊與中央標誌，並未重現使用者提供的參考封底比例，因此實際結果與參考圖差異明顯。封面搜尋介面則直接列出候選來源的所有 ISBN-10／ISBN-13，且在搜尋摘要中再次串列所有解析 ISBN，沒有說明哪些是同一版本的對應碼、哪些是不同版本，造成使用者無法判斷。

本次只修改程式版型與 ISBN 資訊呈現，不生成任何圖片。

## 目標

1. 將使用者提供的第二張封底圖視為固定版型基準，讓預設出版社式封底在位置、比例與留白上接近該參考。
2. 每個封面候選只突出一個建議 ISBN-13。
3. ISBN-10 僅作為同一版本的對應碼說明，不呈現成另一個主要選項。
4. 不同出版社、語言、裝幀、媒介或卷數的 ISBN 才視為不同版本，並清楚標記差異。
5. 保留所有元素可移動、縮放、刪除的現有能力。

## 封底版型

### 版面基準

出版社式封底使用封底安全區作為座標基準，建立三個固定區塊：

- **左上 ISBN 區**：位於安全區左上方，包含一行 ISBN-13 標題及下方 EAN-13 條碼。整體寬度約為安全區的 36%，高度約為 14%。
- **右上出版資訊區**：緊接在條碼右側，與 ISBN 區頂端對齊。寬度約為安全區的 31%，內容依序為出版社、定價、出版地；沒有資料的行不建立。
- **中央標誌區**：水平置中，頂端約在安全區高度的 32%，寬度約為安全區的 48%，高度約為安全區的 36%。圖片使用 contain，維持原比例，不裁切。

ISBN 區與出版資訊區必須形成一個緊湊的左上資訊群，不再把出版資訊推到封底最右側。中央標誌保持大面積留白，沒有圖片時不建立 placeholder。

### 元素行為

ISBN 文字、條碼、出版資訊及中央圖片仍使用專案元素儲存，因此可在畫布中移動、縮放、隱藏或刪除。重新寫入 ISBN 時只更新文字與條碼內容，不重設使用者已調整的幾何位置。

## ISBN 顯示與選取

### 候選卡

每張候選卡顯示：

- 建議 ISBN-13
- 對應 ISBN-10（只有來源提供或可驗證轉換時才顯示，標註「同一版本對應碼」）
- 出版社
- 語言
- 卷數／版本資訊
- 判定理由，例如「書名、作者與卷數相符」

候選卡不再逐行列出未解釋的所有 ISBN。

### 建議 ISBN 規則

1. 優先使用來源直接提供且校驗正確的 ISBN-13。
2. 只有 ISBN-10 時，轉換為對應的 978 ISBN-13 作為建議值。
3. 同一來源項目的 ISBN-10 與其可逆對應 ISBN-13 視為同一版本。
4. 無法與建議 ISBN-13 建立對應關係的號碼，不放入同一版本的補充欄位。
5. 卷數不符的候選不得自動寫入。
6. 專案已有不同 ISBN 時仍需明確確認。

### 搜尋摘要

搜尋完成後不再顯示「解析 ISBN：A、B、C……」。改為：

- 尚未選取時：顯示找到多少個候選版本。
- 選取候選後：顯示「將使用 ISBN-13 …」，必要時補充「對應 ISBN-10 …」。

## 資料模型

維持現有 `SearchCandidate.isbn` 作為建議的標準 ISBN-13，`SearchCandidate.isbns` 保留來源識別碼供內部判定。UI 新增純顯示用的版本摘要函式，不更動專案 schema。若來源可提供 publisher、language、published_date 或 edition 描述，使用現有候選 metadata；缺少資料時顯示「未提供」，不得猜測。

## 測試

新增或更新測試覆蓋：

1. 出版社式封底的 ISBN、條碼、出版資訊及中央標誌區座標比例。
2. 空白欄位不建立元素。
3. ISBN-10／ISBN-13 對應時只產生一個主要建議 ISBN-13。
4. 不相關 ISBN 不被標示為同一版本。
5. 候選卡不再輸出未解釋的 ISBN 清單。
6. 搜尋摘要不再串列所有解析 ISBN。
7. ISBN 寫回後保留條碼與標籤的使用者幾何調整。

## 非目標

- 不生成或內建任何出版社標誌圖片。
- 不自動辨識參考圖中的出版社或價格。
- 不新增新的外部搜尋服務。
- 不改動 Android 端功能。
