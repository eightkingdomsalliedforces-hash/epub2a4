# 現代直排封底、可選書脊與書衣裁切框設計

## 1. 目標

新增一套獨立的「現代直排封底＋可選書脊」模板，依使用者提供的實體書參考圖重建以下特徵：

- 封底頂部放置 ISBN 條碼與出版社資料。
- 封底中段使用由右向左的黑色直排簡介。
- 封底右側使用主題色顯示大型直排醒目文案。
- 書脊提供三種可切換版型，並正確區分中文書名、英文書名、篇章與集數。
- 主題色自動取自封面圖片，並允許使用者手動覆寫。
- 書衣預覽、DOCX 與 PDF 都可顯示完整成品裁切框。

此模板不取代現有的「出版社封底＋直式書脊」。Desktop 與 Android 使用相同的資料模型、模板核心、取色規則與幾何計算。

## 2. 非目標

- 不複製參考圖底部的人物剪影、年級數字、英文裝飾或其他插圖。
- 不從參考照片擷取或重製受著作權保護的圖像素材。
- 不自動撰寫封底簡介或醒目文案。
- 不移除既有出版社模板。
- 不允許任何文字、Logo、條碼或裁切框超出指定的實體區域。

## 3. 模板與資料模型

### 3.1 新模板

新增模板 ID：

`modern_vertical_back_with_spine`

顯示名稱：

`現代直排封底＋可選書脊`

現有 `publisher_back_matter_with_spine` 模板保持不變。

### 3.2 新增中繼資料

新增可選欄位：

- `back_vertical_copy`：封底黑色直排內文。
- `back_highlight_copy`：封底主題色醒目文案。
- `spine_style`：`reference_stacked`、`clean_centered` 或 `parallel_columns`。
- `accent_color_mode`：`auto` 或 `manual`。
- `extracted_accent_color`：最近一次從封面擷取並通過對比校正的顏色。

既有 `spine_accent_color` 繼續作為實際渲染顏色，避免破壞舊專案。

### 3.3 欄位預設值

- 建立新專案時，`back_vertical_copy` 預設帶入 EPUB、PDF 或 Word 擷取到的 `description`。
- `back_highlight_copy` 預設為空，禁止自動生成內容。
- `spine_style` 預設為 `reference_stacked`。
- 有封面圖片時，`accent_color_mode` 預設為 `auto`。
- 沒有可分析的封面圖片時，主題色回退到 `#F15A24`。

### 3.4 使用者編輯

Desktop 與 Android 的出版社／模板欄位增加：

- 「封底直排內文」多行輸入框。
- 「封底醒目文案」多行輸入框。
- 「書脊樣式」選單。
- 「主題色自動擷取」模式與手動顏色控制。

兩種封底文字都可以完整增刪、換行與改寫。修改後即時更新模板元素。套用模板後，對應文字元素仍可在畫布上選取及調整。

## 4. 現代直排封底

### 4.1 頂部資訊

封底安全區頂部採左右排列：

- 左側：ISBN-13 條碼及可選附加碼。
- 右側：出版社、定價、出版／代理資訊、譯者。

缺少的資料行不保留空白，後續資料向上緊縮。譯者有值時必須顯示，不可因字框高度不足而消失。

### 4.2 黑色直排內文

`back_vertical_copy` 位於封底中段偏左：

- 文字由上至下、欄位由右至左排列。
- 欄間使用細分隔線。
- 保留使用者輸入的段落與換行意圖。
- 預設黑色或近黑色。
- 字級、欄距與欄數依內容量自動調整。

內容過長時依序：

1. 在允許範圍內縮小字級。
2. 縮小欄距。
3. 增加可用欄數。
4. 到達最小字級仍放不下時顯示可恢復的版面警告。

系統不得靜默截斷文字。

### 4.3 主題色醒目文案

`back_highlight_copy` 位於封底中段右側：

- 使用比內文明顯更大的粗體。
- 使用自動擷取或手動指定的主題色。
- 直排方向與內文相同。
- 保留使用者輸入的換行。
- 內容為空時移除該區塊，黑色內文可使用釋放出的空間。

### 4.4 底部

參考圖最下面的人物剪影、年級數字、英文裝飾不製作。該區域保持留白，除非使用者之後手動加入元素。

## 5. 三種書脊樣式

使用者可在同一模板中切換三種書脊樣式。切換只重新計算模板管理元素的預設幾何，不清除任何中繼資料。

### 5.1 參考圖分層式

`reference_stacked` 為預設樣式，依序配置：

- 頂部出版社 Logo。
- 英文書名。
- 中文書名。
- 篇章名稱，例如「二年級篇」。
- 圓形集數，例如 `3`。
- 作者。
- 內部書號。
- 出版社名稱與底部方向記號。

英文文字取自英文書名欄位。「二年級篇」取自篇章欄位，不得誤當集數。圓形數字才取自集數欄位。

### 5.2 極簡置中式

`clean_centered` 保留：

- Logo。
- 中文書名。
- 篇章名稱。
- 圓形集數。
- 作者。
- 出版社。

英文書名與內部書號在此樣式中預設隱藏，但資料仍保留。

### 5.3 雙欄現代式

`parallel_columns` 使用平行直欄：

- 中文書名與篇章為主欄。
- 英文書名為副欄。
- 集數使用圓形主題色徽章。
- 作者、內部書號與出版社置於下方。

### 5.4 寬度自適應

三種樣式都必須依實際書脊寬度產生完整、緊湊與極窄配置：

- 所有元素的實際矩形必須位於 `spine_rect` 內。
- Logo 使用 `contain`，保持比例，不裁切、不溢出。
- 次要資訊在窄書脊可隱藏，但中文書名、篇章或集數、出版社保持可辨識。
- 無法在最低字級安全顯示時給出警告，不輸出越界元素。

## 6. 主題色擷取

### 6.1 自動模式

從實際封面圖片取樣並計算代表色：

- 排除接近白色、接近黑色與低飽和灰色。
- 優先選擇具有足夠像素占比且飽和度較高的色群。
- 使用固定且可測試的量化／分群規則，確保同一圖片得到相同結果。
- 若選出的顏色與白色背景對比不足，降低亮度直到達到最低可讀對比。
- 無有效候選色時使用 `#F15A24`。

更換封面時，只有 `accent_color_mode == auto` 才重新擷取。

### 6.2 手動模式

使用者修改顏色後：

- `accent_color_mode` 切換成 `manual`。
- 更換封面不覆蓋手動顏色。
- 使用者可執行「重新從封面擷取」回到自動模式。

同一主題色同時供封底醒目文案、書脊篇章、集數徽章及其他模板重點元素使用。

## 7. 書衣完整裁切框

### 7.1 顯示規則

使用者選擇完整裁切框，而不是四角短裁切線：

- 裁切框沿書衣成品外框，也就是 `spread_rect` 的四條邊。
- 書脊兩側仍使用獨立的折線／組裝導線，不與裁切框混為一種線。
- 預設線寬為 `0.35 pt`。
- 裁切框不可超出 `bleed_rect`。

### 7.2 預覽與輸出一致

`show_crop_marks` 為唯一開關：

- 開啟時，Desktop 預覽、Android 預覽、DOCX 與 PDF 都顯示相同裁切框。
- 關閉時，所有預覽與輸出都不顯示裁切框。
- 四個消費端必須使用共享核心產生的同一組毫米座標，不得各自重算。

## 8. 更新與手動調整

- 中繼資料更新只替換內容並重新計算需要自動排版的模板元素。
- 使用者手動移動、縮放或旋轉元素後，普通文字更新應盡量保留其變換。
- 切換書脊樣式屬於明確的版面重排操作，可以更新書脊模板元素幾何，但不得清除欄位內容。
- 「重設模板版面」恢復現代封底與目前書脊樣式的預設幾何。
- 切換回既有模板不刪除現代模板的中繼資料。

## 9. 錯誤處理

- 封面圖片無法解碼時保留目前主題色並顯示警告。
- 自動取色失敗時使用預設色，不阻止專案建立或輸出。
- 文字溢出時顯示具體欄位名稱與需要處理的原因。
- 缺少 Logo 時移除 Logo 元素並讓後續書脊內容使用可用空間。
- 無效書脊樣式值載入時回退至 `reference_stacked`。
- 舊專案缺少所有新欄位時仍可正常載入。

## 10. 測試

### 10.1 資料與相容性

- 新欄位序列化、反序列化及舊專案預設值。
- EPUB 簡介只在初次建立時填入 `back_vertical_copy`。
- 編輯兩種封底文字後儲存、重開仍一致。
- 三種書脊切換不遺失資料。

### 10.2 現代封底

- 條碼與出版社資訊位置。
- 譯者有值時必定顯示。
- 黑色內文由右向左分欄並產生分隔線。
- 醒目文案使用主題色。
- 空白醒目文案會釋放版面。
- 長文字縮排後不越界，無法容納時產生警告而非截斷。
- 底部不產生參考圖的裝飾元素。

### 10.3 書脊

- 三種樣式的元素集合與語意對應。
- 英文書名、篇章與集數不互相混用。
- 完整、緊湊與極窄書脊皆不越界。
- Logo 保持比例並位於書脊內。
- 切換樣式保留中繼資料。

### 10.4 主題色

- 固定圖片得到確定的代表色。
- 黑、白、灰候選被排除。
- 低對比顏色被校正。
- 自動模式換封面會更新。
- 手動模式換封面不更新。
- 取色失敗使用 `#F15A24`。

### 10.5 裁切框與平台

- 共享核心輸出 `spread_rect` 四邊裁切線。
- 開關控制 Desktop、Android、DOCX 與 PDF。
- 四個消費端的毫米座標一致。
- 裁切框線寬為 `0.35 pt` 且不超出出血範圍。
- 執行完整 Python 與 Desktop 測試。
- 建置 Android APK 與 Windows Portable。

## 11. 發佈

此功能以 `v0.7.0` 發佈。

流程：

1. 功能分支推送並建立 PR。
2. Android、Desktop 與 Windows CI 全部通過後合併。
3. 在合併提交建立 `v0.7.0` 標籤。
4. 標籤自動建立 GitHub Release。
5. Release 包含 Android APK、Windows Portable ZIP 與 `SHA256SUMS.txt`。

## 12. 驗收標準

- 使用者可選擇獨立的現代直排封底模板，原模板不受影響。
- 封底黑色內文與主題色醒目文案都可獨立編輯。
- 現代封底的上方及中段配置與參考圖一致，底部裝飾不製作。
- 三種書脊樣式都可選，預設為參考圖分層式。
- 英文書名、篇章名稱與集數使用正確欄位。
- 主題色會從封面自動擷取，且手動覆寫不被換封面操作覆蓋。
- 完整裁切框同時出現在預覽、DOCX 與 PDF，並受同一開關控制。
- 所有模板元素和線條都不超出其指定範圍。
- Desktop 與 Android 使用相同核心規則。
- 完整測試、安裝包建置、PR CI 與 `v0.7.0` 自動 Release 全部成功。
